1. Installation
Dependencies
The plattar-ar-adapter SDK has dependencies on the following open-source projects:

plattar-api - Used for interfacing with the Plattar API
plattar-web - Used for managing various embeds for Scenes and Products
plattar-qrcode - Used for generating Plattar Styled QR Codes
These dependencies are automatically installed and bundled via NPM. No additional actions are needed to resolve these dependencies.

Install via NPM
Use NPM to install the latest version of the plattar-ar-adapter SDK for a new or existing project:

npm install @plattar/plattar-ar-adapter

Install via JS Embed
The SDK is also available as a pre-built and packaged JavaScript bundle that can be used for projects without NPM support.

See the plattar-ar-adapter repository for alternative built packages.

Use the following script to embed the latest version of the pre-built plattar-ar-adapter SDK on your existing website:

<script src="https://sdk.plattar.com/plattar-plugin.min.js"></script>
